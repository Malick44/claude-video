# Restricted

Crime-scene photos, images of victims, and anything else sensitive or sealed go here.

- Nothing in this folder is committed. `.gitignore` excludes every file here except this README.
- Keep it on the local machine only. Don't copy it into a cloud session, a shared drive or an upload.
- Register each file in `00_research/evidence.json` with `"restricted": true`, and refer to it by that ID only.
- Material from here stays out of the edit by default. Using any of it needs a reviewed decision in `09_clearance/`.
- Never store sealed court material, not even here.
