# Facebook Page setup

Create a **Page for NOBODY MOVES**, administered by the owner's authorized Facebook account. Use [`COPY.md`](COPY.md) for all public profile text and [`POST_001.md`](POST_001.md) for the first Reel and welcome post. Launch with Version A.

| Page field | Paste or upload |
|---|---|
| Page name | `NOBODY MOVES` |
| Category | Choose the available creator/video entertainment category closest to `Digital creator`; verify the wording in the current Page UI |
| Username | Shared handle chosen in `../LAUNCH_HANDOFF.md`, if Facebook allows it and it is available |
| Bio / Intro | Version A short bio in `COPY.md` |
| About / Description | Version A About paragraph in `COPY.md` |
| Profile image | `art/avatar_title.png` (alternate: `art/avatar_character.png`) |
| Cover image | `art/cover_clue.jpg` (alternate: `art/cover_witnesses.jpg`) |
| Website / contact / address / hours | Leave blank until the owner provides real values; do not use fictional Birchwood Court as the Page location |
| Action button | Use a watch/video destination only when a real public Episode 1 or playlist URL exists; otherwise leave the default Page action |

Inspect the cover on desktop and phone after upload: Facebook crops it differently by surface. Keep the title in the image's center safe region. If Facebook accepts custom cover alt text, use: `NOBODY MOVES case-board cover for a fictional lawn-ornament mystery.`

The Page can be complete before the first Reel without claiming a post is pinned. Once Case 001 is live, add the welcome post from `POST_001.md`, feature or pin it if the Page UI permits, and add the YouTube/TikTok links after those accounts have actual public URLs. Keep Page moderation on for spam, but preserve good-faith theories; this is an interactive mystery.

For the first Reel and later photoreal episodes, use the platform's current AI/synthetic-content disclosure when available. The public bio, About text, and caption clearly call the work fictional. Save the actual Page URL, username, chosen copy/art version, and status in the account registry.
