# TikTok account setup

Use this with [`COPY.md`](COPY.md) and [`POST_001.md`](POST_001.md). **Version A** is the launch choice. The art files in `art/` are upload-ready; the source script is `../make_launch_art.py`.

| Field | Paste or upload |
|---|---|
| Display name | `NOBODY MOVES` |
| Username | Shared handle selected in [`../LAUNCH_HANDOFF.md`](../LAUNCH_HANDOFF.md), only after checking live availability |
| Profile photo | `art/avatar_title.png`; `art/avatar_character.png` is the alternate |
| Bio before first upload | Version A pre-post bio in `COPY.md` |
| Bio after Episode 1 is posted and pinned | Version A live bio in `COPY.md` |
| Website | Add only if the field is available and the target URL exists; first choice is the YouTube Season 1 playlist after it is public |
| Linked social accounts | Link the actual YouTube account if TikTok offers the integration; use the account registry for the verified URL |

Create the show account with the owner's authorized login. Do not choose an unavailable handle merely to match the file. Check the round profile crop at small size; the yellow title art is designed for that view. A TikTok profile has no channel banner. Use deliberate covers on the first posts so the grid reads in case order.

Once Case 001 is live, pin it if the app offers pinning. If playlists are available on this account, create `Season 1 | Birchwood Court` after the first episode is public; later add `Confessionals` when one exists. Neither should be claimed in the bio before it exists. Check link availability in the app; TikTok's website field is conditional, so the account can still be ready to post without a link.

For each photoreal episode, use TikTok's AI-generated content disclosure during upload. The bio and caption also say the story is fiction. Verify visibility, cover crop, sound, captions, and the question in the first comment after posting. Record the live URL and status in a working copy of `../account_registry.template.json`.
