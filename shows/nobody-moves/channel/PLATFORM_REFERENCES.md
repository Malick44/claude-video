# Platform checks for the account agent

These are official platform sources checked on 2026-09-28. Platform forms change, so use the live UI as the final check when creating the accounts. The copy and images in this kit deliberately leave margin for cropping and field limits.

## TikTok

- [Profile photo setup](https://support.tiktok.com/en/getting-started/setting-up-your-profile/adding-a-profile-photo-or-video): TikTok publishes a small minimum image size; this kit's 1080-square avatars exceed it.
- [Nickname rules](https://support.tiktok.com/en/getting-started/setting-up-your-profile/changing-your-nickname): nickname up to 30 characters and a seven-day change interval. `NOBODY MOVES` fits.
- [Username rules](https://support.tiktok.com/en/getting-started/setting-up-your-profile/changing-your-username): username characters and change timing; verify each candidate in the app before setting it.
- [Social links and website eligibility](https://support.tiktok.com/en/getting-started/setting-up-your-profile/linking-another-social-media-account): social account connections vary; the website field has account eligibility requirements.
- [AI-generated content disclosure](https://support.tiktok.com/en/using-tiktok/creating-videos/ai-generated-content): realistic AI-generated images, audio, or video must be labeled. This series uses photoreal AI visuals.

The TikTok bios in this kit are all under 80 characters as a conservative writing target. TikTok's official support did not expose a current universal bio cap in this research; the account agent should verify the live field.

## Facebook Page

- [Page profile and cover help](https://www.facebook.com/help/125379114252045): official cover-photo help page. It required a login in our research session, so preview the supplied 1640×624 cover on phone and desktop and reposition if the Page crop differs.
- [Page access and management](https://www.facebook.com/help/289207354498410/r.php/): create/manage with the owner's authorized account.
- [Page action buttons](https://www.facebook.com/help/messenger-app/1638565256396310): only add a destination when a real public target URL exists.
- [Meta's AI content labels](https://about.fb.com/news/2024/02/labeling-ai-generated-images-on-facebook-instagram-and-threads/): check the current disclosure option for photoreal AI-assisted video and keep the explicit fiction language in the Page and Reel copy.

Facebook's Page bio, username, and exact cover crop limits were not verifiable from an accessible official help page in this session. The Page agent should check the current composer rather than treating a third-party number as a hard rule.

## YouTube

- [Channel banner and profile art](https://support.google.com/youtube/answer/10456525): recommended 2560×1440 banner, central safe area for text, and a 6 MB banner limit. This kit's banners use the recommended canvas and central title card.
- [Handle rules](https://support.google.com/youtube/answer/11585688): verify the candidate handle in Studio; YouTube limits handle length and allowed characters.
- [Custom Shorts thumbnails](https://support.google.com/youtube/answer/72431?hl=en): a **verified** account can upload a 9:16 image in Studio on a computer, including after a Short is posted. The 1080×1920 JPGs in `youtube/art/` are intended for this field.
- [Create or upload Shorts](https://support.google.com/youtube/answer/10343433?hl=en-GB): phone app also lets the creator choose a video frame; Shorts can run up to three minutes in the current help workflow.
- [Channel links and description](https://support.google.com/youtube/answer/2657964): add verified cross-links after accounts exist.
- [Audience selection](https://support.google.com/youtube/answer/9527654?co=GENIE.Platform%3DDesktop): select whether content is made for kids based on the actual audience; made-for-kids designation affects comments.
- [Altered or synthetic media disclosure](https://support.google.com/youtube/answer/14328491): use the relevant disclosure setting for realistic AI-assisted scenes.

The 80.1-second pilot candidate is a 1080×1920 H.264/AAC MP4 at 30 fps. Technical metadata was checked locally; its creative/editorial approval remains a separate review before upload.
