# NOBODY MOVES — account launch kit

This is the handoff for creating the show's TikTok, Facebook Page, and YouTube channel. Nothing in this folder means those accounts have been created or the first episode has been posted.

**Start with [`LAUNCH_HANDOFF.md`](LAUNCH_HANDOFF.md).** It names the preferred copy and art, the order of account setup, the first video source, and the checks a future account agent should perform. Each platform folder has ready-to-paste profile and first-post text plus its own art. The [`launch contact sheet`](launch_contact_sheet.jpg) and [`ART_GUIDE.md`](ART_GUIDE.md) show the visual options. [`ENGAGEMENT_PLAYBOOK.md`](ENGAGEMENT_PLAYBOOK.md) explains how to use the variants; [`PLATFORM_REFERENCES.md`](PLATFORM_REFERENCES.md) links the current official setup rules.

**Live browser setup:** [`ACCOUNT_SETUP_STATUS.md`](ACCOUNT_SETUP_STATUS.md) records the current account-creation state and any owner-only steps.

Keep the episode-one hidden change out of public bios, titles, covers, and replies until viewers discover it. Describe the show as **scripted fiction / mystery comedy** because the photoreal scenes mimic a crime documentary.

The original TikTok/Instagram/YouTube planning notes are retained in [`CHANNEL_LEGACY.md`](CHANNEL_LEGACY.md) for reference. The files linked above supersede them for this launch.
