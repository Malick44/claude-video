# YouTube channel setup

Create a channel for the show under the owner's authorized Google account. Launch with Version A in [`COPY.md`](COPY.md); use [`POST_001.md`](POST_001.md) when the first Short is approved for publication.

| Channel field | Paste or upload |
|---|---|
| Channel name | `NOBODY MOVES` |
| Handle | Shared handle selected in `../LAUNCH_HANDOFF.md`, after checking YouTube availability |
| Profile picture | `art/avatar_title.png` (alternate `art/avatar_character.png`) |
| Banner | `art/banner_clue.jpg` (alternate `art/banner_witnesses.jpg`) |
| Description / About | Version A in `COPY.md` |
| Channel keywords | Version A keyword line in `COPY.md`, if the Studio field is present |
| Links | Add real TikTok and Facebook Page URLs only after those accounts exist; do not invent links |
| Video watermark | `art/watermark.png` if supplied and if it remains readable in the preview; optional |

Inspect the banner preview on phone, desktop, and TV crop. The source artwork is 2560×1440; text is concentrated in the center safe area. Use the title avatar across all accounts even if the banner changes with a season. If a screen reader description is supported for any channel art, use: `NOBODY MOVES: fictional mystery case board with lawn-ornament witnesses.`

After the first video is public, create `Season 1 | Birchwood Court` and place Case 001 first. Create a `Confessionals` playlist only once a Confessional is public. Add a Start Here section or featured Short if Studio offers it; verify that a visitor who is not subscribed sees Episode 1 first. A channel trailer is optional and not supplied as a video in this kit; do not upload a still image as a trailer.

For a realistic AI-assisted Short, make the relevant altered/synthetic-content selection in the upload flow. The channel description and video description also identify the series as fiction. Record the public channel URL, chosen art/copy version, link status, and first-post status in the account registry.
